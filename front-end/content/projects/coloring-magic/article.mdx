## Description

Coloring Magic Art is a production web app for creating custom coloring books with AI, from first idea to printed book. Users describe a theme, upload a photo or attach a recurring character, pick one of nine image models, and generate up to 50 pages per run, with up to 100 pages and a full-color front cover in one book.

Books export as images or print-ready PDFs in portrait, landscape or square formats. Built-in Amazon KDP and Lulu printing profiles set the trim size, bleed and page layout, so a book can go from the editor to a self-publishing platform without manual reformatting. The site is available in seven languages and includes weekly free sample PDFs, a blog with prompt and publishing guides, and an MCP server for using Coloring Magic Art from AI assistants like Cursor and Claude.

## Main features

- Marketing site with problem/solution/workflow sections and weekly sample PDF downloads by age group
- MDX blog with article pages at `/blog` and `/article/[slug]`
- Nine image models (GPT Image 2.5/2.6, Grok Imagine, Gemini, Seedream; default GPT Image 2.5 Sunburst) via Vercel AI SDK
- AI prompt generation using OpenAI GPT-4o-mini for turning user descriptions into detailed image prompts
- Up to 50 pages per wizard run plus covers; up to 100 pages per book
- Age-appropriate output ranging from simple (kids 2-5) to intricate (adults)
- Vertical, horizontal A4, and square layouts; print-ready PDF export with Amazon KDP and Lulu printing profiles
- Photo-to-page and character sheet inputs; full-color front covers
- Seven locales (EN, DE, NL, IT, ES, FR, SV)
- MCP server (https://coloringmagic.art/mcp, guide https://coloringmagic.art/article/coloring-magic-art-mcp-server)
- Async image processing pipeline with SQS and Lambda
- Token-based payment system with Stripe integration
- Weekly free sample PDF generation via Step Functions orchestration
- Google OAuth and email/password authentication
- Drag-and-drop page reordering in the editor
- Real-time job status polling with optimistic updates
